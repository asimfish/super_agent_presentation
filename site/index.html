Agent-native reporting framework

Give an agent the same task twice and you get two differently shaped reports. This framework makes the shape a contract.

Scenario-routed report protocols, bounded context bundles, checkpointed long-task memory, and mechanical structure audits — installable into Claude Code, Codex, Cursor, and GitHub Copilot, or usable by any agent that can read one Markdown index. The honest before/after: a real strict-audit repair trajectory

Most demo pages show only the final polished output. This one shows the failure log too. When the 12 core-mode showcase reports were first drafted, the checkpoint-bound audit --strict passed 1 of 12. Three repair rounds later, all 12 passed — without adding a single fact beyond the evidence bundle and without loosening strict mode. Click through the rounds; every finding below is quoted from the committed failure log.

Repair principle, quoted from the log: “补充真实存在的语义标签与表格说明，合并过度标题； 不添加证据包以外的事实，不降低 strict。” The audit forces the report to surface what is already true — it never invents content to pass.

Also in the same log: the semantic oracle itself started at 6/16 because its forbidden-substring check flagged explicit negations ("cannot claim significance") as violations. The fix went into the oracle (negation-aware matching), never into the reports — facts were not rewritten to appease a broken check. Full trail: first-failures.md · audit-summary.md

How one report is produced

The same seven steps ran for all 16 showcase reports and the deck. The audit in step 6 reads the same on-disk checkpoint written in step 3, so the contract survives context compaction in long tasks.

1Freeze tasktask text is fixed before routing
2Routedeterministic mode + profile choice
3Checkpointcontract written to disk
4Bounded bundleprotocol context under an explicit char budget
5Writeagent drafts against the bundle
6Strict auditsame-checkpoint structural check
7ReceiptsJSON receipts committed with the report

Where it sits among the alternatives

This is a mechanism comparison, not a measured-outcome claim — the project deliberately refuses to assert quality gains it has not measured. Each row is a property you can verify from the code.

Mechanism Bare prompting Style guide in system prompt One big report template This framework
Per-scenario report structure (short answers stay short) ———✓ 12 routed modes

The last row is intentional: the audit verifies structure and evidence discipline, never truth. A framework that claimed otherwise would be overclaiming — which is exactly what its protocols forbid.

Two ways to start

Fastest: link-only trial (no install)

Paste this into any agent that can fetch a URL. It reads one bounded index, routes your task, and reports — nothing is written to your project.

请先读取该仓库的 AGENT_START.md，
并用其中的最小路由完成本次最终汇报；
不要读取全部协议。仓库：
https://github.com/asimfish/super_agent_presentation

Full: install as a skill

Installs the protocol tree and reportctl into your project for Claude Code, Codex, Cursor, or GitHub Copilot. Dry-run first, apply when happy.

git clone https://github.com/asimfish/super_agent_presentation.git
cd super_agent_presentation
python3 scripts/install.py apply \
  --target /path/to/your/project --host codex
