Agent-native reporting framework

The same task should not produce a differently shaped, unreadable report every time.

Scenario-routed report protocols, bounded context bundles, checkpointed long-task memory, and mechanical structure audits — installable into Claude Code, Codex, Cursor, and GitHub Copilot, or usable by any agent that can read one Markdown index.

Open the live demo deck View on GitHub

A real output: 7-page assertion–evidence academic deck built with the academic-talk-html template, printed through real Chrome, with every audit receipt kept in the repository. Facts on the slides are synthetic fixtures.

How it keeps reports consistent

Route, don't template

12 primary report modes, 5 display modules, and 4 research profiles. Each task loads one bounded protocol — short answers stay short, experiment reports carry protocol, runs, and uncertainty.

Survive long tasks

A tiny resident micro-contract saves an on-disk checkpoint at task start; the final audit is driven by the same checkpoint, so the reporting contract outlives context compaction.

Audit mechanically

A stdlib-only CLI (reportctl) bundles bounded context and runs structural audits with honest limits: it checks structure, never claims your facts are true.
