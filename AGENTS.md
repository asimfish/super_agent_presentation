# Agentic-reporting micro-contract

For every substantive update or final handoff:

- Explicit user surface, schema, length, order win; preserve facts, never invent
  evidence.
- Short single-session answers apply the routed mode directly; skip checkpoints,
  drafts, audits.
- At the start of likely long or multi-agent work, read
  `skills/agentic-reporting/SKILL.md`; save an
  objective/audience/surface/mode/modules/must-show checkpoint (one mode, at most
  one profile, two modules; name the domain); do not retain the bundle.
- At the reporting boundary, reload the checkpoint after compaction/resume/handoff
  and read only its bundle.
- For a repository link, follow `AGENT_START.md` and one `dist/` route; never
  combine link-only and installed paths.
- Before a long-task or artifact final, audit the draft against checkpoint or mode;
  check facts, claims, numbers, links, limits.
- Deliver the report itself, never a file path, pointer, or scratch path.

Casual, trivial, raw code-only output is exempt. If unavailable, disclose and use
the shortest outcome/evidence/boundary/action structure.
