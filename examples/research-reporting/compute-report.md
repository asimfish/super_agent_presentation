# 记忆系统的收益尚未与额外计算分开

带记忆系统在这组比较中困惑度更低，但实验同时改变了记忆模块和推理预算，
还没有回答“收益是否来自记忆检索”。目前支持的是两个系统在各自预算下的比较。

同一骨干、训练数据、留出语料和提示集合下，困惑度从 36.0 降至 32.0，推理
token 预算同时从 1× 提到 2×。额外 token 预算仍是一个未排除的解释；检索相关上下文
是方法提出的机制，尚未被这项对照单独验证。

下一项实验拟比较同一 2× 预算下的带记忆与无记忆系统，固定骨干、数据和提示。
同时记录检索开销，token 预算相同还不等于总计算量相同。若带记忆仍有收益，
进一步检查检索内容的作用；若无记忆追平，则额外 token 预算仍足以解释这组
系统差异，暂停以此结果论证记忆贡献。这项对照尚未执行。
